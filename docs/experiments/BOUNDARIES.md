# Publication boundaries

## Included

This catalog indexes files already on public `vision-arcade` main at `1b41d197be7d7203df5f191d380f8c1ac723125e`, and links the existing public learning branch. Original public MVP assets retain their existing licensing and attribution. Catalog text and its validation test are the only additions; no new local model, reference image, screenshot, recording, archive, financial source, fixture or credential is imported.

## Held-back families

- **Private Sentinel studies (withheld):** Private source, local references and derivatives have not been cleared for public release.
- **Knight, Paladin and equipment studies (review-required):** Mixed original work and externally sourced models, animation and textures. Redistribution rights and exact inclusion scope need review.
- **Connected gameplay and navigation prototypes (review-required):** Local deployment bundles mix app source, private calculator composition, assets and generated output. No bundle was imported.
- **Standalone asset inspection utilities (review-required):** Candidate tooling exists locally, but authorship, license and reproducibility have not been established.
- **Private financial implementation and fixtures (withheld):** Outside the public repository boundary. No private source or detailed contents included.

A private source may contain original geometry and still be private. A local attribution note or an asset being viewable online is not proof of redistribution rights. No license is newly assigned to withheld work by this catalog.

Before any future import: identify the exact source files and their owner, obtain the required release approval, verify asset licenses and attribution, isolate a reproducible self-contained example, inspect its complete dependency tree and history, scan for secrets and private implementation, and run the public release gate. Do not copy entire local workspaces or their Git history.

## Preserved

Original local folders and existing remote branches remain unchanged. The private calculator, calibration and implementation are outside this branch. The public hosted-service adapter and contract remain unchanged. Build outputs, logs, dependency trees, temporary files and large binary bundles are not part of this change.

This is a bounded audit of identified Vi$ion project folders and the public repository, not a claim to have searched every disk or recovered every historical conversation.
